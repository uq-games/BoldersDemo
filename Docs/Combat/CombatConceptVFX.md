# 战斗特效：示意图还原

这版采用战士 A 的冷白刀锋和 B 的双手剑厚度，弓箭手用 A 的普通箭和 B 的元素命中，法师用 B 的立体造型和 A 的细落雷预警圈。美术范围由现有攻击数据驱动，伤害、冷却、命中规则、元素反应和装备不由特效决定。

| 职业 | 对照点 | UE 里的配置入口 |
| --- | --- | --- |
| 战士 | 冷白细边、突刺针形高光、双手剑厚暖边、收招迅速熄灭 | 五个攻击蒙太奇的 `Blade VFX` 通知轨；材质 `M_WarriorBladeTrail` |
| 弓箭手 | 普通箭的细金线、弹射的薄荷绿折线和箭头、爆炸箭的橙色火瓣与分段冲击圈、冰冻箭的冰晶簇 | `DA_ArcherAttackLoadout` 的 Presentation；冰晶簇由受击角色的冻结标签控制 |
| 法师 | 火球卷焰、水浪卷边和白沫、细紫预警与垂直落雷、六面冰锥和短命碎块 | `DA_MageAttackLoadout` 的网格、材质、预警和碎片配置 |

冻结簇绑定受影响角色的 GAS 状态；冻结结束或被碎冰等反应提前解除时，两端各自清除。冰锥碎片是视觉网格，带短距抛射，不参与碰撞或伤害。其余攻击表现继续复用已有的投射物或命中通知。

再生成脚本是 `Scripts/Editor/setup_combat_concept_vfx.py`。它会覆盖这次制作的材质、模型和对应的表现字段，保留原有玩法字段与现有元素反应资源。战士的局部调节见 [战士刀光拖尾](WarriorBladeTrail.md)。

验证：UE 5.9 Editor 构建成功，资产生成与回读通过。TestMap 使用职业选择和实际攻击命令验证十招，涵盖两套战士武器、四种箭、四种法术。另单独检查五个战士攻击蒙太奇及中途换装，双人 PIE 验证冻结晶簇在双方生成并随碎冰效果清除。

火球和海浪的第二版在 `DA_MageAttackLoadout` 中分别配置主体、附加模型、飞行粒子和尾迹。火球是亮核心叠三股有独立轮廓的卷焰，后方用火星和薄烟拉出距离；海浪由留出卷腔的青蓝浪身、立体白沫浪帽和脱离浪头的水滴组成。飞行粒子在显示端按世界坐标模拟，离开投射物后继续衰减，不改变服务器的命中、范围和伤害。

需要重新生成这两招时运行 `Scripts/Editor/setup_mage_layered_vfx.py`。如果整批重新生成了初版概念资产，最后再执行此脚本覆盖火球和海浪的表现字段。

第二版在 TestMap 中各试射两次，确认主体、附加模型、尾迹和飞行粒子均启用；命中后残余粒子继续衰减并清除。两个独立目标分别损失 32 点和 23 点生命。截图与测试记录位于 `Saved/MageLayeredVFX/`。
