# BoldersDemo 求职 Demo 视频制作总控执行手册

> **求职定位**：UE5 玩法 / 战斗系统客户端开发（Gameplay / Combat Systems）  
> **成品结构**：分 P1（实机游玩演示，约 2 分 45 秒）与 P2（核心 C++ 架构与代码解析，约 4 分 45 秒）  
> **分工方式**：本手册与文案/分镜/截图清单由 Antigravity 产出；**ChatGPT（Computer Use）** 负责在本地执行 UE5 实机游玩、OBS 录屏、Rider 高清代码截图、以及**必剪（Bcut）**剪辑与「**曼波讲故事**」AI 配音合成。

## 一、视频成品规格与核心卖点

| 项目 | 规格要求 |
| --- | --- |
| 分辨率与帧率 | `1920 × 1080`（16:9），`60 fps`（P1），`30/60 fps`（P2） |
| 封装与编码 | `MP4`（H.264，码率 12~16 Mbps，画面清晰不糊字） |
| 配音音色 | 必剪内置 AI 配音 —— **「曼波讲故事」**，语速 `1.05x ~ 1.10x`（稳健不拖沓，适合技术讲解） |
| 字幕规范 | 底部居中，黑底半透描边或深色阴影，微软雅黑/思源黑体，字号适中不遮挡技能栏与代码底行 |
| 音频混音 | AI 配音 `-3 dB ~ -6 dB`（清晰为主）；P1 游戏原声 `-14 dB ~ -18 dB`（战斗爆发可短暂抬至 `-10 dB`）；背景音乐 `-24 dB ~ -28 dB`（低存在感史诗/科技氛围，绝不压人声） |

### 面试官 30 秒内必须看到的 6 个核心硬实力
1. **不是蓝图玩具，是完整 UE5 C++ 玩法框架**：GAS 属性/抗性/自定义伤害执行 + 数据驱动招式模块（`UAttackLoadout`）。
2. **真·元素反应与环境机关连锁**：9 条表驱动反应规则（冻结/碎冰/融化/感电连锁/超载冲击/蒸发等）+ 4 类可交互机关（喷口/冷却槽/炸药桶/导柱）+ 战士槽边蘸刀附魔。
3. **直控动作手感工程化打磨**：固定俯视镜头 WASD 直控、0.44s 攻击预输入缓冲、自定义 `CharacterMovementComponent` 前摇防滑步、无效机关元素防空耗冷却。
4. **纯 C++ 驱动的大型 Boss 战**：自定义 `FAnimInstanceProxy` 采样混合、斜坡贴地三维跳劈、45% 血量延迟狂暴衔接保留反击窗、预警与命中帧误差 < 10 ms。
5. **服务端权威双人联机（Listen Server）**：100 ms 模拟延迟实测通过、穿队友不挡弹道、检查点 50% 血复活、胜负结算同步。
6. **工业级工程素养**：7 项 UE 原生自动化测试 + 实机帧耗时剖析与独立包启动/退出验证。

### 推荐执行流（人机协作）
1. **你 -> ChatGPT**：先发 **Stage 1（环境准备与 OBS 配置）**，确认 OBS 1080p 60fps 与 UE Standalone 窗口正常出画、有声、不掉帧。
2. **你 -> ChatGPT**：发 **Stage 2（P1 分段游玩录屏）**，让它按 7 个片段逐一录制到 `01_RawRecordings\`；每录完 1~2 段你快速抽看 5 秒确认画面无穿帮/无卡死。
3. **你 -> ChatGPT**：发 **Stage 3（Rider 代码截图）**，一次性截完 15 张高清 PNG 到 `02_RiderScreenshots\`。
4. **你 -> ChatGPT**：发 **Stage 4（必剪剪辑 + 曼波讲故事 AI 配音）**，先出 P1 成品，再出 P2 成品。
5. **你 -> ChatGPT**：若发现某段字幕遮挡、语速太慢或红框偏位，直接发 **Stage 5（成片自检与返工）** 做局部精修。

## 四、给「曼波讲故事」AI 配音的防翻车规则

1. **文案已预先做“听感适配”**：口播稿中已避免连串难以朗读的英文驼峰标识符（如不直接念 `UBoldersCombatMovementComponent::ConstrainInputAcceleration`），改为自然中文术语（如“自定义移动组件重写输入加速度约束”），而精确类名与函数名通过 **Rider 画面 + 屏幕左上角技术标签** 直观呈现。
2. **缩写词读法检查**：试听时重点检查 `UE5`、`C++`、`GAS`、`Boss`、`HUD`、`PIE` 的发音是否顺耳；如果「曼波讲故事」把 `GAS` 误读成奇怪英文或吞字，可在必剪配音文本里局部替换为 `G A S` 或 `能力系统`，但**底部字幕仍保持专业写法 `GAS`**。
3. **分段生成语音，不要一整篇塞进同一个文本框**：按分镜表中的 `Shot / 章节` 分段生成配音条，这样画面变速、对齐技能命中瞬间和切换 Rider 截图时最容易精准卡点！
