# BoldersDemo

Developed with Unreal Engine 5

这是一个模仿博德之门战斗系统的极简化demo

项目目录、资产导入与命名约定见 [项目文件与资产组织规范](Docs/ProjectOrganization.md)。

默认关卡为火山铸造岛。选职业后，用 WASD 沿岛面移动，左键点选敌人或机关攻击。沿路击败两波守卫后可挑战熔炉骑士。路线、操作和机关机制见 [火山战斗关卡](Docs/Maps/VolcanoCombat.md)。分项自评和实机验证见 [打磨记录](Docs/Maps/VolcanoCombatPlaytest.md#铸造岛重做)。

第一次读源码可以从 [代码阅读与整理笔记](Docs/CodeGuide.md) 开始，按点击移动、普攻和职业选择三条流程追踪。
